Extract lines

Deterministic pass: the confirmed mapping names the columns, Python copies the actual values — no model, no invented numbers. Meter points are matched to RYE's site list; anything unmatched is flagged, never silently accepted.

Site reference / incumbent (sites_*.csv — optional)
One file, two jobs: overrides site names + EAC/kVA here, and provides the incumbent contract at the assemble step. Any dated Retool export works as-is (e.g. sites_2026-07-31_122851.csv) — no need to rename it. Leave empty to use the quote's own figures with no incumbent baseline.
